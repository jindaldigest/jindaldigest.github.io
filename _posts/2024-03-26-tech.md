**Scraping Requirements:**

1.  **Target Websites:**
    
    *   [Flipkart](https://www.flipkart.com/)
        
    *   [Amazon.in](https://www.amazon.in/ref=nav_logo)
        
2.  **Scope of Data:**
    
    *   All SKUs of Laptops category from both websites need to be scraped and matched.
        
    *   Important fields are the Specifications, Prices, Product titles, Brand and Series Name.
        
    *   Image is not high priority but could be scraped to help in matching

**Data Processing:**

1.  **Cleaning and Validation:**
    
    *   Notes on Cleaning:
        
        *   “Type“ - Column M can have only 2 values - {“Gaming Laptops“ , ”Non - Gaming Laptops”}
            
        *   “Screen Brightness“
            
            *   Most of the cases, do not have screen brightness mentioned but some do.
                
                *   They are usually in the product title like: “Lenovo LOQ Intel Core i5-12450H 15.6" (39.6cm) FHD IPS 144Hz _**350Nits**_ Gaming Laptop (16GB/512GB SSD/Win 11/NVIDIA RTX 2050 4GB Graphics/Office 2021/3 Month Game Pass/Storm Grey/2.4Kg), 82XV00F4IN“
                    
                *   Or in the Product description. Like this case: [https://www.flipkart.com/lenovo-loq-intel-core-i5-12th-gen-12450h-16-gb-512-gb-ssd-windows-11-home-4-graphics-nvidia-geforce-rtx-2050-15irh8-gaming-laptop/p/itma2ce6d6c8705b?pid=COMGRFVBJKVSZKSS&lid=LSTCOMGRFVBJKVSZKSSEILAF1&marketplace=FLIPKART&q=Lenovo+LOQ+Intel+Core+i5-12450H&store=6bo/b5g&srno=s\_1\_3&otracker=search&otracker1=search&fm=Search&iid=1c4e1d22-b03f-4a0c-ba1a-15a3783c90f0.COMGRFVBJKVSZKSS.SEARCH&ppt=pp&ppn=pp&ssid=o3w14f8e8w0000001705654122338&qH=f93c2142fe29d8d9](https://www.flipkart.com/lenovo-loq-intel-core-i5-12th-gen-12450h-16-gb-512-gb-ssd-windows-11-home-4-graphics-nvidia-geforce-rtx-2050-15irh8-gaming-laptop/p/itma2ce6d6c8705b?pid=COMGRFVBJKVSZKSS&lid=LSTCOMGRFVBJKVSZKSSEILAF1&marketplace=FLIPKART&q=Lenovo+LOQ+Intel+Core+i5-12450H&store=6bo/b5g&srno=s_1_3&otracker=search&otracker1=search&fm=Search&iid=1c4e1d22-b03f-4a0c-ba1a-15a3783c90f0.COMGRFVBJKVSZKSS.SEARCH&ppt=pp&ppn=pp&ssid=o3w14f8e8w0000001705654122338&qH=f93c2142fe29d8d9)
                    
        *   “Generation“
            
            *   Ryzen Processors have a different naming convention, “5500U“ indicates “5000 series”; 3300U indicates 3000 Series. The series needs to be noted for Ryzen chips
                
            *   For Mediatek, MT8183 is same as “MediaTek Kompanio 500“ hence, only one of the 2 should be used and not both. Similarly, we have 2 names for all Mediatek chips and only one of teh 2 should be used, ideally the “MediaTek Kompanio YYY“ form instead of “MTXXXX“.
                
        *   ”SSD”
            
            *   Presently, it is a boolean field, one more Boolean field of “HDD“ needs to be added.
                
            *   Both HDD and SSD need to be “Yes“ for Hybrid Storage.
                
            *   SSD as “YES“ and HDD as “NO“ for only SSD storage and vice-versa.
                
        *   “SSD Capacity“
            
            *   Along with this, one more field of HDD capacity needs to be added for HDD or Hybrid storage.
                
            *   Example:
                
                *   HP 15s, 11th Gen Intel Core i3 8GB RAM/1TB HDD+256 GB SSD 15.6-inches/39.6 cm FHD Laptop/Windows 11/Intel UHD Graphics/Dual Speakers/Alexa/MSO/Fast Charge/1.75 Kg, 15s-du3614TU
                    
                *   The above needs to be captured as: HDD: “YES”; SSD: “YES“; HDD CAPACITY: 1TB; SSD CAPACITY: 256GB.
                    
        *   “RAM Type“
            
            *   Only “DDR“ is captured in a couple of cases, DDR6 is the actual value.
                
        *   “Screen Size“
            
            *   Stick to only the inches value, any other values should be converted to inches.
                
        *   “Key Board“
            
            *   We need to indicate if the laptop has backlit keyboard, this field is not always given in the specifications but is indicated in the product title. Example: [https://www.flipkart.com/lenovo-thinkbook-13s-intel-core-i5-11th-gen-1135g7-8-gb-512-\[…\]-2-thin-light-laptop/p/itm4e80c69aad36a?pid=COMG6YZZCK4AVDFP](https://www.flipkart.com/lenovo-thinkbook-13s-intel-core-i5-11th-gen-1135g7-8-gb-512-gb-ssd-windows-10-home-tb13s-itl-2-thin-light-laptop/p/itm4e80c69aad36a?pid=COMG6YZZCK4AVDFP)
                
        *   “Number of Cores“
            
            *   If this field is missing it can be obtained from the title
                
    *   Data needs to be completely uniform for example
        
        *   Key words for RAM size should be uniform. If we choose GB and TB as the metric, Gb, gb, gbs, GBS, Terabyte are all unacceptable
